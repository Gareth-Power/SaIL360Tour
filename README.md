# SaIL Centre 360 Tour

This project is a simple 360 degree virtual tour of the SaIL Centre.

It is built from the Marzipano tour template and serves a set of pre-generated panorama tiles through a static HTML, CSS, and JavaScript app.

## Project structure

- `index.html` sets up the page shell and viewer controls.
- `index.js` initializes the Marzipano viewer and scene navigation.
- `data.js` defines the scenes, initial camera positions, and hotspots.
- `tiles/` contains the panorama image tiles for each scene.
- `img/` contains the interface icons used by the viewer.
- `vendor/` contains third-party frontend libraries used by the template.

## Running locally

Open `index.html` in a browser, or serve the folder with any simple static web server.
